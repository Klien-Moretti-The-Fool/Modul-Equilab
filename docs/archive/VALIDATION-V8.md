# Pengesahan EQUILAB V8

Semakan pada 11 Oktober 2026 untuk projek React/Vite ini.

## Pengiraan dan binaan

- `npm test`: 20 ujian lulus, termasuk ujian V7 serta 5 ujian model makmal tambahan.
- `npm run build`: binaan produksi Vite berjaya.
- Imbangan cas akueus, trend pencairan, kapasiti penimbal dan empat pasangan titrasi disemak.
- Model gas mengekalkan stoikiometri semasa relaksasi dan memenuhi Q = K pada keadaan akhir.
- Kesan mampatan membezakan perubahan jumlah NO₂ daripada kepekatannya; ilustrasi warna menggunakan kepekatan.
- Campuran dinamik dari A sahaja, B sahaja dan campuran 1:1 menghampiri komposisi yang sama dengan kadar bukan sifar.

## Pelayar

- Chromium: lima makmal × dua bahasa × enam lebar skrin = 60 keadaan paparan.
- Lebar 1440, 1366, 1024, 768, 390 dan 320 px; tiada limpahan mendatar dalam keadaan yang diuji.
- Interaksi: pencairan, asid/bes, kuat/lemah, tiga garam, pili buret automatik, dos manual, empat pasangan titrasi, tiga penunjuk, had 50 mL, dua pipet penimbal, dos 0.5/1 mmol, henti pengacau, had ±12 mmol, mula/jeda/ulang masa dan lapan gangguan gas.
- Enam aktiviti berpandu: ramalan, jalankan, penjelasan salah, pembetulan, selesai dan set semula.
- Telefon 390 dan 320 px: paparan kawalan menunjukkan bacaan langsung; bertukar ke radas mengekalkan nilai eksperimen.
- Paparan selepas memilih makmal pada 1366 × 768: pemilih kekal di atas, tajuk tidak bertindih, penerangan utama penimbal berada dalam tinggi skrin.
- Tiada ralat JavaScript atau console error dalam aliran yang diuji. Tangkapan paparan diperiksa secara visual.

## Pemasang

- Kemas kini daripada salinan V7 asal, pemasangan ulangan, sumber CRLF/BOM, penolakan suntingan tersendiri serta pakej rosak diuji.
- Sandaran sepadan dengan fail asal. Simulasi kegagalan salinan memulihkan perubahan yang sudah ditulis.
- `.env`, pautan video tersendiri, kandungan modul dan aset gambar tidak diganti oleh pemasang.

## Batas semakan

Pengujian automatik ini mengesahkan aliran tertentu, bukan jaminan bahawa tiada pepijat dalam semua keadaan. Akaun Supabase sebenar, kelas guru/pelajar dan pangkalan data tidak diuji dengan akaun langsung. Pemasang diuji dengan Node dalam persekitaran Linux; arahan PowerShell disediakan untuk Windows tetapi belum dijalankan pada komputer Windows pengguna.

Sahkan kefahaman dan kebolehgunaan bersama pakar kimia serta pelajar sasaran. Animasi dan radas ialah model pendidikan; ia tidak menggantikan amalan keselamatan atau eksperimen makmal sebenar.
